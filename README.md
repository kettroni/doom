# Doom Emacs configuration

## Custom libraries

Personal Emacs Lisp libraries live in `libraries/`. `config.el` adds this
folder to `load-path` before loading the custom OpenCode client.

## Customize state

`custom.el` is generated by Emacs Customize and is gitignored. Doom loads it
after `config.el` by default, so its saved values can override settings in
`config.el`. Keep generated or machine-specific Customize state there; move
only deliberately chosen, portable settings into `config.el` by hand, then
remove duplicate Customize entries if you want the tracked config to control
them.

## Machine-local configuration

Credentials are loaded from the gitignored `secrets.el`. Copy
`secrets.el.example` to `secrets.el` on a fresh machine and set the local
OpenCode server password there.

Project-, employer-, and machine-specific settings belong in the gitignored
`local.el` (for example, private remote directory mappings or local paths).
On a fresh machine, copy `local.el.example` to `local.el` and add that machine's
private settings. The standard config loads both files optionally, with
`local.el` loaded after credentials and before OpenCode notifications start. Keep private code and
identifiers out of tracked files; secrets and personal customizations are
separate concerns.

Do not put credentials in tracked files. If a credential was previously
committed, remove it from active use and rotate it; moving it now does not
remove it from existing repository history.
